# Olist E-commerce — Metabase Dashboards

This folder contains the **Metabase dashboards** developed to analyze the Olist E-commerce Data Warehouse.

## Dashboards

* **Executive Overview** — Overall business performance and key KPIs.
* **Sales Analysis** — Sales trends, orders, revenue, and top-performing products.
* **Customer Analysis** — Customer distribution, locations, and purchasing behavior.
* **Seller & Operations** — Seller performance and order activity.
* **Logistics Analysis** — Delivery performance, delivery time, and freight costs.

## Technology

* **Database:** PostgreSQL
* **BI Tool:** Metabase
* **Dataset:** Olist E-commerce Dataset

The dashboards provide an interactive view of the data and help transform the Olist dataset into actionable business insights.
