# Olist-Metabase-Analytics 
1. Project Overview

This project focuses on the analysis of the Olist E-commerce Data Warehouse using Metabase. The objective is to transform the data stored in PostgreSQL into interactive dashboards and business insights.

2. Data Source
Olist E-commerce Dataset
        ↓
PostgreSQL Data Warehouse
        ↓
Metabase
        ↓
Interactive Dashboards

3. Dashboards

Tu présentes tes 5 dashboards :

Executive Overview
Sales Analysis
Customer Analysis
Seller & Operations
Logistics Analysis

Pour chacun : capture + quelques KPI + objectif de l'analyse.
4. Technologies

PostgreSQL • SQL • Metabase • Data Warehouse • Business Intelligence

Et pour Metabase

Tu gardes ton instance Metabase connectée à ta base PostgreSQL olist_bi, puis tu publies/partages tes dashboards.

Le résultat final peut être présenté ainsi :

GitHub = documentation + SQL + screenshots
Metabase = dashboards interactifs
